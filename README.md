# lark-docs-to-md

Export Lark Docs and Wiki pages to local Markdown files.

## Goal

`lark-docs-to-md` will provide a reliable way to download content from Lark
documents and Wiki pages to a local computer in Markdown format, preserving
the structure and assets needed for local reading and archival.

The project may be used through a command-line interface, a Codex Skill, or a
web interface. The export behavior and local Markdown output are the shared
core.

## Status

Repository initialized. Implementation and export conventions are still to be
designed.

## Initial Scope

- Accept a Lark document or Wiki URL.
- Resolve the underlying document when a Wiki URL is supplied.
- Export content to local Markdown with a predictable asset layout.
- Keep authentication material out of the repository and generated output.
